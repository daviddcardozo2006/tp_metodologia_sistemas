# git branch

El comando `git branch` permite gestionar las ramas del repositorio.

## Listar ramas locales

```bash
git branch
```

## Listar ramas locales y remotas

```bash
git branch -a
```

## Crear una nueva rama

```bash
git branch nombre-de-la-rama
```

## Eliminar una rama

```bash
git branch -d nombre-de-la-rama
```
